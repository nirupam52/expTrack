# AGENTS.md

## Role
You are building a production-quality personal expense tracker.

## Priorities (highest first)
1. Correctness
2. Performance
3. Simplicity
4. Maintainability
5. Visual polish

## Communication
- For user communications, speak in ASD-STE100 only. 
- Do not tell me "non-goals" or what you "won't" do. 
- No dead prose.

## Coding Standards
- Always follow industry best practices and the idiomatic conventions of the language and framework in use.
- Follow existing project structure.
- Keep functions focused.
- Write readable code.
- Avoid duplication.
- Add tests for business logic.
- Do not introduce dependencies without justification.

## UX Rules
- Minimize clicks.
- Minimize typing.
- Mobile-first.
- Fast interactions.
- Sensible defaults.

## Performance Constraints
- UI should feel instantaneous.
- Avoid unnecessary re-renders.
- Keep API payloads small.
- Avoid unnecessary database queries.

## When Unsure
Choose the simplest implementation that satisfies current requirements.
Do not implement future features unless explicitly requested.
